# Azure OpenAI Samples Japan

[English](README.md) | [日本語](README.ja.md)

Azure OpenAI reference applications for Japanese-market use cases, including call-center assistance, recipe suggestions, goal support, company research, document search, and landing-zone infrastructure.

## Included use cases

- [Call-center assistant](1.call-center/)
- [Recipe adviser](2.recipe-adviser/)
- [Goal-achievement adviser](3.goal-achievement-adviser/)
- [Company research](4.company-research/)
- [Internal-document search](5.internal-document-search/)
- [Azure OpenAI landing-zone accelerator](6.azureopenai-landing-zone-accelerator/)

Each sample provides its own architecture, code, and deployment instructions. The original project was published by volunteer employees of Microsoft Japan; this repository is a copy under moruku36.
